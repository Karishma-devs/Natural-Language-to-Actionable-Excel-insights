# Natural Language to Actionable Excel Insights

🔗 **Live Demo:** https://natural-language-to-actionable-excel-insights.streamlit.app/

## 📊 Project Overview
Developed an automated system converting natural language prompts into structured Excel data models with 95%+ accuracy. Optimized data transformation workflows to analyze high-volume data quickly while maintaining strict quality control.

This project turns raw Excel/CSV data into actionable insights using natural language queries - no need to write complex formulas!

## 🚀 Key Features
- 📂 Upload CSV or Excel files
- 🧹 Automatic data cleaning & preprocessing
- 💬 Ask questions in plain English: e.g., "Show sales by region", "Top 5 products by revenue"
- 📈 Auto-generate charts (Bar, Line, Pie, Scatter)
- 📊 Get quick insights (averages, top values, trends)
- ⚡ 95%+ accuracy in query conversion

## 🛠️ Tools & Skills
Python, MySQL, Advanced Excel, Data Analysis, Process Automation, Streamlit, Pandas, Plotly

## 📂 How It Works
1. User uploads Excel file
2. Data is cleaned using Pandas
3. User inputs query in natural language
4. System converts query into data operation
5. Results displayed as charts and summaries
